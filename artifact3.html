Artifact 3: Grazioso Salvare Dashboard

Databases

For my databases artifact, I selected the Grazioso Salvare Rescue Dashboard, which was originally created in CS 340. This project was designed to display animal shelter data in an interactive dashboard format so that users could view and work with the data more easily. The original project focused on presenting rescue-animal information in a visual and accessible way. For this enhancement, I revisited the artifact and improved its structure, filtering logic, and usability to better reflect the role of databases in storing, retrieving, and organizing information.

I chose this artifact because it best represents my ability to work with data-driven applications, which is an important part of database development. Even though the project uses a CSV data source, the application still demonstrates core database concepts such as loading structured data, filtering records based on user input, and presenting meaningful information in a way that supports decision making. I felt this artifact was a strong choice for my ePortfolio because it shows that I can build an application that retrieves, manipulates, and displays data while also focusing on the user experience.

As part of the enhancement, I improved the application by restructuring the code and adding a database-style query function. Instead of leaving the dashboard as a simple static display, I created filtering options that allow the user to refine the data by rescue category and animal type. This made the application more interactive and helped it better reflect how real database-backed systems allow users to request only the information they need. I also added error handling for the data-loading process so that the program responds more reliably if there is an issue with the file or the application setup. These changes made the artifact more organized, more maintainable, and more useful from both a technical and user perspective.

This enhancement aligns most directly with the course outcome focused on using well-founded and innovative techniques, skills, and tools in computing practices to implement computer solutions that deliver value and accomplish industry-specific goals. By improving the dashboard, I demonstrated my ability to create a data-driven solution that is not only functional but also easier to use and extend. The enhancement also supports the outcome related to designing and evaluating computing solutions, because I had to think through how users would interact with the data and how the filtering logic should be structured to make the application more effective. In addition, the written portion of this milestone supports the communication outcome because it required me to explain my work clearly and professionally.

One thing I learned during this enhancement process is that building a working application is only part of the job. It is just as important to organize the code clearly, make the data interactions meaningful, and think about how the user will experience the system. When I first worked on projects like this in earlier coursework, my main goal was usually just to get the program running. During this enhancement, I paid more attention to structure, readability, and how the logic of the application could better represent database operations. That shift in thinking helped me better understand what it means to improve software instead of simply completing it.

A challenge I faced was that I no longer had full access to the original course environment, so I had to work from the project files I was able to recover and rebuild the artifact in a way that still met the milestone requirements. I also had to troubleshoot environment and compatibility issues while getting the dashboard to run again in Visual Studio Code. Working through those issues reminded me that debugging and adaptation are important parts of software development. Rather than giving up when the original setup was unavailable, I adjusted the artifact into a working standalone version and still completed a meaningful enhancement.

Overall, this artifact belongs in my ePortfolio because it demonstrates growth in my ability to work with structured data and create applications that support user interaction with that data. The enhanced dashboard shows my understanding of data filtering, application structure, visualization, and reliability. More importantly, it reflects how my skills have developed over time. I now approach projects with a stronger focus on maintainability, usability, and real-world application. This enhancement helped me see that database work is not only about storing information, but also about designing systems that make that information useful.
