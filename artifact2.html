Artifact 2: Pirate Intelligent Agent

Algorithms and Data Structures

The artifact selected for this enhancement is the Pirate Intelligent Agent developed in CS-370. This project involved designing and training an agent using deep Q-learning to navigate a maze environment and successfully reach a goal location. The original artifact demonstrated the foundational implementation of reinforcement learning concepts, including state representation, action selection, and reward-based learning. However, there were opportunities to improve how the agent learned from its environment, particularly in how rewards influenced its decision-making.

I selected this artifact for my ePortfolio because it directly showcases my understanding of algorithms and data structures, specifically in the context of reinforcement learning and decision-making processes. The project highlights how an agent interacts with an environment, evaluates possible actions, and updates its behavior over time based on feedback. This aligns closely with algorithmic problem solving and demonstrates my ability to apply computational thinking to dynamic scenarios.

The primary enhancement focused on improving the reward system within the environment. In the original implementation, the reward values did not strongly differentiate between effective and ineffective actions, which could lead to inefficient learning or excessive exploration. To address this, I modified the reward structure to provide a stronger positive reward for reaching the goal, increased penalties for invalid or unproductive actions, and introduced clearer consequences for revisiting previously explored states. These changes encouraged the agent to prioritize efficient paths and reduce unnecessary movement.

In addition to refining the reward system, I addressed inconsistencies between components of the project, including improving compatibility between the environment, experience replay system, and training loop. These adjustments ensured that the agent could properly store and learn from past experiences, resulting in more stable and effective training. As a result of these enhancements, the agent demonstrated improved learning behavior, achieving successful outcomes more consistently within fewer training iterations.

Through this process, I was able to meet the course outcomes related to designing and evaluating computing solutions using algorithmic principles. This enhancement demonstrates my ability to analyze an existing solution, identify areas for improvement, and implement changes that optimize performance while considering trade-offs such as exploration versus exploitation. It also reflects my ability to work with data structures such as arrays and memory buffers to support learning algorithms.

One of the key lessons learned during this enhancement was the importance of reward design in reinforcement learning. Small changes in reward values can significantly impact how an agent behaves and learns. I also encountered challenges related to debugging interactions between different components of the system, which required careful analysis to ensure consistency across the environment, training loop, and experience replay mechanism. Overcoming these challenges strengthened my understanding of how complex systems integrate multiple algorithmic components.

Overall, this enhancement demonstrates my ability to apply algorithmic thinking, improve existing systems, and develop more efficient and effective computational solutions. It represents meaningful progress toward my growth as a computer science professional and highlights my ability to refine and optimize intelligent systems.
