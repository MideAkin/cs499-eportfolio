Artifact 1: Airgead Banking Application

Software Design and Engineering

Artifact Description: The artifact selected for this enhancement is the Airgead Banking Application, originally developed in CS-210. This application is a C++ program that calculates and displays investment growth over time, both with and without monthly deposits. Users input financial information such as an initial investment amount, monthly contribution, interest rate, and number of years, and the program generates yearly reports showing balances and earned interest.

Justification for Inclusion: I selected this artifact because it represents one of my earlier experiences applying object-oriented programming and financial calculation logic to solve a real-world problem. It demonstrates foundational software engineering concepts such as structured program design, user input handling, and iterative calculations.

Several components of this artifact highlight my skills. The use of a dedicated class (InvestmentCalculator) demonstrates my understanding of object-oriented design and encapsulation. The program also uses loops to simulate financial growth over time and applies formatted output to present results in a readable way.

As part of the enhancement, I improved the program’s modularity by separating the input validation process into its own function. This made the code more organized and easier to maintain. I also strengthened input validation to ensure that users cannot enter invalid or negative values, improving the reliability of the application. Additionally, I refined the output formatting using formatting tools such as setw and setprecision to create a more professional and readable report. These improvements enhanced both the functionality and usability of the application.

Course Outcomes Alignment: This enhancement aligns with the course outcome of designing and evaluating computing solutions using appropriate software engineering practices. By restructuring the code and improving validation, I demonstrated the ability to create a more reliable and user-friendly solution.

The enhancement also reflects my ability to use well-established tools and techniques in software development. Applying input validation, modular design, and improved output formatting shows progress in writing cleaner and more professional code. These improvements contribute to developing solutions that are more maintainable and aligned with industry expectations.

Reflection on the Enhancement Process: Working on this enhancement helped me better understand the importance of writing clean, modular, and user-focused code. While the original version of the program was functional, it lacked the level of structure and validation expected in professional software development.

One of the main challenges I faced was modifying the structure of the program without breaking its existing functionality. Separating input validation into its own function required careful testing to ensure that all inputs were still handled correctly. Additionally, refining the output formatting required attention to detail to ensure that the program’s output remained accurate while becoming more readable.

Overall, this process reinforced the importance of improving both the functionality and presentation of software. I learned that even small changes, such as better organization and clearer output, can significantly improve the quality of a program. This experience has strengthened my confidence in enhancing existing code and applying software engineering principles in future projects.
